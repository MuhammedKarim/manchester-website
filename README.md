# Khanqah Naqshbandia Mujaddidia website

A simple responsive static website split into clean files.

## Structure

- `index.html` — semantic page content
- `css/styles.css` — layout, design system, responsive styles
- `js/main.js` — mobile menu, sticky header state, scroll reveal
- `assets/` — place site images here

## Timetable image

The page currently includes an elegant placeholder for the monthly timetable. To use a real timetable, add your image as `assets/timetable.jpg`, then replace the placeholder block in `index.html` with:

```html
<img src="assets/timetable.jpg" alt="Current monthly timetable" />
```

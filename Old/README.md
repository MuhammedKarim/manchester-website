# Khanqah Naqshbandia Mujaddidia website

A simple responsive static website split into clean files.

## Structure

- `index.html` — semantic page content
- `css/styles.css` — layout, design system, responsive styles
- `js/main.js` — mobile menu, sticky header state, scroll reveal
- `assets/` — place site images here

## Timetable image

The May 2026 timetable image is included at `assets/timetable-may-2026.png`. The hero and navigation download links point directly to this PNG using the `download` attribute.
